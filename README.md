# AI Vacation Planner — Backend

FastAPI backend for the Vacation Planner capstone. Users can register, log in, and create trips with itineraries.

> A full setup guide and architecture overview will land in a later PR. For now, this README is intentionally minimal.

## Stack

- Python 3.12 with [uv](https://docs.astral.sh/uv/)
- FastAPI
- PostgreSQL (via Docker Compose)
- SQLAlchemy + Alembic
- JWT authentication

## Status

In active development.
